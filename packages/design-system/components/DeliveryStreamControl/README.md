# DeliveryStreamControl

The delivery stream control: a fieldset of four native radios, one per peer stream, with a visible advisement and a separate Apply, hosted by PRIM-001 in every stream and re-hosted by the World primitives. Hand-written from `docs/phase-1-ui-reference-design/DESIGN_SYSTEM_IMPLICATIONS.md` section 3.4 as amended under D-047 (design set `HD/Shell and navigation/Delivery stream control`; no new primitive ID).

**When to use.** On every route in every stream, in the same position under the same name, reachable without a canvas and without traversing main content; on the first frame of the home route with the canvas not entered; in `S-SEMANTIC` in the utility navigation, reachable through the narrow disclosure at 320 CSS px.

**Provide.** A `<form>` whose page status region already exists, empty, before any message is written; the `fieldset` and a `legend` that names the control and the in-force stream; four native radio inputs sharing one name, each labelled with the visible stream label (gated copy, UG-3); the advisement paragraph inside the fieldset before Apply, associated with the fieldset and with Apply through `aria-describedby`, identical wording in every stream; the Apply submit button whose accessible name states that it applies the selection and differs from the group and radio names; for a stream above the WebGL ceiling, the `disabled` radio plus a visible reason stated as a fact about the client.

**Anatomy and classes.** `.hd-stream-control` (the fieldset: `hd-border-strong` boundary on `hd-surface-canvas`, no shadow), `.hd-stream-control__legend` with a `span` for the in-force segment, `.hd-stream-control__options` list of `.hd-stream-control__option` rows, `.hd-stream-control__reason` for the unavailable text, `.hd-stream-control__advisement`, and `.hd-stream-control__apply` on a `.hd-button.hd-button--secondary`. Add `.hd-stream-control--hud` inside the World HUD so focus uses the scene ring. Native radios are not restyled (UG-7). Targets are at least 24 by 24 CSS px in every stream.

**Activation.** Arrow, Tab, pointer or touch among the radios change only the checked state. The stream applies only on explicit Apply (Enter, Space, pointer, touch, or native Enter submission of the same form); never on focus, selection, blur, arrow movement or timeout. A select applying on change, and any listbox, combobox, menu or radio group applying on selection, are prohibited.

**Names and announcement.** The group name reports the in-force stream until submit; the checked radio reports the pending selection independently; pending never looks or reads as applied. A change is announced politely in the status region without moving focus within a shell. Across the semantic boundary the outgoing shell leaves the accessibility tree, the incoming shell and its empty status region are added, focus moves to the destination control, visibly indicated and reporting the new stream, and the announcement names the new stream and the arrival location. Booking process state survives every crossing or the change is refused and explained.

**States.** Pseudo-states base, hover, focus-visible, pressed and disabled on each radio and on Apply (hover and pressed pairings gated); the transactional states `stream-in-force` and `stream-pending`; the frame states `STATE-STREAM-CHANGED`, `STATE-PREFERENCE-WRITE-FAILED`, `STATE-PREFERENCE-READ-FAILED` and `STATE-STREAM-CEILING-REFUSED`, each with visible text and a non-colour cue. Unavailable and explanation text never use the error or attention status alone: the reason is a fact about the client, not a failure the visitor caused.

**Keyboard and focus.** One tab stop into the group, arrows among the radios, Apply a separate tab stop; nothing bound to Escape; focus-visible uses `hd-focus-ring` on semantic shells and the scene ring in the HUD, measured per stream and never obscured by the HUD panel.

**Modes.** 320 CSS px, 400% zoom with the advisement still before Apply and unclipped, text spacing, forced colours (checked, in-force, focus and unavailable state distinguishable without authored colour), grayscale, reduced motion, unavailable font and image.

**Don't.** Apply a stream on selection; hide, or dim without text, an above-ceiling option; word a label as a fallback, reduced or lesser mode; bind Escape; move focus on a same-shell change; number or rank the streams.

**Gated.** Exact public copy for labels, legend, advisement, reasons and announcements (UG-3); scene ring colour, offset and sampling method (UG-1, UG-2); whether Apply is ever disabled (UG-5); hover and pressed pairings (UG-6); native radio styling under forced colours (UG-7). The component tokens `--hd-delivery-stream-control-*` exist as names in the frozen file and carry no value yet.
